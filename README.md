# دار الخماسة — DAR EL KHAMASA 🛍️

منصة تجارة إلكترونية متكاملة لعلامة واحدة، مبنية خصيصاً للبيع عبر **صفحات هبوط موحدة احترافية** (قالب واحد + بيانات ديناميكية لكل منتج)، مع إدارة طلبات كاملة بـ workflow المكالمات اليدوي، وشحن **DHD Express**، ومخزون، ومالية، وتحليلات.

## Stack

- **Next.js 14** (App Router) + React 18 + TypeScript
- **Tailwind CSS** — هوية بصرية: بني داكن `#21160F`، ذهبي `#C99A45`، ذهبي فاتح `#E7BD75`، بيج دافئ `#F5E7D7`، كريمي `#FFF8EF` — عربي RTL كامل
- **Supabase** — جاهز للربط (schema كامل في `db/migrations/`)
- طبقة بيانات محلية JSON (`lib/db/store.ts`) تعمل فوراً بدون قاعدة بيانات — **تُستبدل بـ Supabase لاحقاً بنفس واجهة الخدمات**

## التشغيل السريع

```bash
npm install
cp .env.example .env.local   # عدّل ADMIN_EMAIL / ADMIN_PASSWORD / SESSION_SECRET
npm run dev                  # http://localhost:3000
```

- الإدارة فقط: `/admin` — الدخول الافتراضي `admin@darelkhamsa.dz` / `admin123` (**غيّرها قبل النشر!**)
- صفحات المنتجات للزبائن: `/p/[slug]` — الزبون يصل مباشرة من إعلان فيسبوك/إنستغرام
- لا توجد واجهة تصفح عامة — الصفحة الرئيسية `/` تُحوّل إلى تسجيل الدخول

## بنية صفحة الهبوط الموحدة `/p/[slug]`

شريط علوي داكن (هاتف/توصيل/عرض) → Header (شعار + من نحن + تواصل) → Hero مقسوم (نص + أسعار + خصم + تقييمات / صورة + شارة) → شريط ثقة → لماذا تختار منتجنا؟ → معرض صور (تكبير + فيديو) → تفاصيل ومواصفات → آراء العملاء → نموذج الطلب → أسئلة شائعة → فوتر داكن — **كل المحتوى من بيانات المنتج عبر لوحة الإدارة**، والرابط يُولّد تلقائياً من اسم المنتج.

## سير الطلبات

1. الزبون يرسل الطلب من صفحة الهبوط → يظهر في الإدارة بحالة **جديد**
2. نسخ رقم الهاتف (زر نسخ) → اتصال يدوي → تسجيل نتيجة المكالمة
3. أزرار سريعة: **لا يُجيب / غير مؤكد / تأكيد الطلب**
4. بعد التأكيد: **إنشاء الشحنة وطباعة التيكت** (DHD API عند توفر التوكن، وإلا تيكت محلي قابل للطباعة) → تتبع → الحالات حتى التوصيل/الإرجاع
5. الطلبات المؤكدة فقط تُخصم من المخزون وتُحسب في المالية (صافي الربح = التوصيل − التكاليف − المصاريف)

## تكامل DHD

- صفحة **الشحن** ← أدخل التوكن ← "اختبار الاتصال"
- بدون توكن: النظام يعمل بجدول أسعار ثابت + شحنات محلية قابلة للطباعة
- مع توكن: إنشاء شحنات حية، أسعار API، تتبع، ملصقات
- المحوّل في `lib/shipping/dhd.ts` — **طابق نقاط النهاية مع وثائق DHD الرسمية قبل الإنتاج**

## النشر على Vercel

1. ارفع المستودع إلى GitHub ثم "Import Project" في Vercel
2. أضف متغيرات البيئة من `.env.example`
3. ملاحظة: تخزين JSON و `public/uploads` مؤقت على Vercel — عند ربط Supabase تنتقل البيانات والصور إلى Supabase (Storage) نهائياً

## ربط Supabase لاحقاً

- نفّذ `db/migrations/0001_init.sql` في مشروع Supabase
- استبدل `lib/db/store.ts` وطبقة الخدمات باستعلامات Supabase — الواجهة (types + actions) لن تتغير
- الصور تنتقل إلى Supabase Storage عبر تعديل `uploadFile` في `lib/actions.ts`
